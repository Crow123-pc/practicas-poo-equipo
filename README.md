# Practicas-poo-equipo

Prácticas de Git, GitHub y programación orientada a objetos del curso Técnicas de Programación Orientada a Objetos.

## Objetivo del repositorio

Desarrollar las prácticas de Git, GitHub y programación orientada a objetos del curso.

## Entrega de las semanas 12 y 13

El proyecto de talleres de bienestar digital está en [bienestar-digital](bienestar-digital/). Documenta 40 requerimientos y 40 historias de usuario; RF01 a RF25 están implementados. El proyecto NetBeans incluye 58 pruebas ejecutables y conserva los registros en CSV UTF-8.

El informe, el formato actualizado de historias y el JAR ejecutable están en [outputs/semanas_12_13](outputs/semanas_12_13/). Para abrir, compilar y probar el software, seguir las instrucciones de [bienestar-digital/README.md](bienestar-digital/README.md).
