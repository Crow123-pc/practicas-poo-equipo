# Practicas-poo-equipo

Prácticas de Git, GitHub y programación orientada a objetos del curso Técnicas de Programación Orientada a Objetos.

## Objetivo del repositorio

Desarrollar las prácticas de Git, GitHub y programación orientada a objetos del curso.

## Entrega de las semanas 12 y 13

El proyecto de talleres de bienestar digital está en [bienestar-digital](bienestar-digital/). Documenta 40 requerimientos y 40 historias de usuario; RF01 a RF25 están implementados. El menú de consola y las 58 pruebas del servicio corresponden a esa entrega.

El [informe integral de las semanas 1 a 13](outputs/semanas_12_13/Informe_integral_semanas_1_a_13.pdf), el formato actualizado de historias y el JAR ejecutable están en [outputs/semanas_12_13](outputs/semanas_12_13/). Para abrir, compilar y probar el software, seguir las instrucciones de [bienestar-digital/README.md](bienestar-digital/README.md).

## Evaluación T3

La actualización T3 añade [tres vistas Swing](bienestar-digital/src/bienestar/AppSwing.java) y una [matriz RF a controles](bienestar-digital/docs/matriz_trazabilidad_t3.md). `ant test-gui` ejecuta 58 casos del servicio y una prueba de navegación, eventos, validación, tablas y persistencia. El [informe final](outputs/t3/Informe_final_T3_semanas_1_a_13.pdf), la [presentación individual](outputs/t3/Sustentacion_T3_POO_Mario_Saucedo.pptx) y el [guion](outputs/t3/Guion_y_preguntas_T3_Mario.md) están en `outputs/t3`. El código T3 se revisa en el [PR #5](https://github.com/Crow123-pc/practicas-poo-equipo/pull/5).
